# Frontend 100 Projects

A progressive, project-based frontend learning path aligned with the major stages of the frontend roadmap.

## Roadmap

| Projects | Stage |
|---|---|
| 01–10 | HTML Fundamentals |
| 11–20 | CSS Fundamentals |
| 21–30 | CSS Layout & Responsive Design |
| 31–40 | Advanced CSS & UI |
| 41–50 | JavaScript Fundamentals |
| 51–60 | JavaScript Data & Programming |
| 61–70 | DOM & Browser |
| 71–80 | JavaScript Applications |
| 81–90 | Async JavaScript & APIs |
| 91–95 | TypeScript |
| 96–100 | React + TypeScript |

## Rules

- Build each project yourself before looking for complete solutions.
- Use documentation and targeted questions when blocked.
- Do not copy an entire solution without understanding it.
- Commit progress with Git.
- Rebuild important projects from scratch after learning them.
- Increase quality expectations as the project number increases.
