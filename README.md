# Frontend Learning Journey — 100 Projects

A structured, hands-on journey to learn **Frontend Web Development** by building 100 projects from basic HTML pages to complete real-world web applications.

The goal is simple:

> **Learn frontend development by building, not just reading.**

This repository is organized into **10 categories**, with **10 projects in each category**, creating a progressive path from HTML fundamentals to modern JavaScript, APIs, and complete frontend applications.

---

##  Main Goal

Build a strong practical foundation in frontend development by completing **100 projects** covering:

- HTML
    
- CSS
    
- Responsive Design
    
- Flexbox
    
- CSS Grid
    
- Advanced CSS UI
    
- JavaScript
    
- Arrays & Objects
    
- DOM Manipulation
    
- Browser APIs
    
- Events & Forms
    
- Asynchronous JavaScript
    
- Fetch API
    
- REST APIs
    
- Modern JavaScript
    
- Real-world frontend applications
    

By the end of the journey, you should be comfortable creating interactive, responsive, and API-powered web applications.

#  Recommended Workflow

For each project:

### 1. Understand

Read the project's `README.md` and understand the requirements before writing code.

### 2. Build

Create the project using the technologies currently being studied.

### 3. Test

Open the application in your browser and test different inputs and screen sizes.

### 4. Improve

Refactor the code and improve the UI where appropriate.

### 5. Document

Update the project's README with what you learned and how the project works.

### 6. Commit

Use Git to save your progress.

```bash
git status
git add .
git commit -m "feat: complete project"
git push
```

#  Project Philosophy

These projects are designed to be **small, focused, and practical**.

Instead of trying to learn everything at once, each project focuses on a specific group of concepts.

The difficulty gradually increases:

```text
Beginner
   ↓
HTML Pages
   ↓
CSS Components
   ↓
Responsive Layouts
   ↓
JavaScript Logic
   ↓
Data Manipulation
   ↓
DOM Applications
   ↓
Browser Projects
   ↓
API Applications
   ↓
Real-World Projects
```

The goal is not simply to finish 100 projects.

The goal is to understand **why the code works**, become comfortable solving problems independently, and build a portfolio of practical frontend projects.
